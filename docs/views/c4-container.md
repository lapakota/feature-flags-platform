# C4, уровень 2 — контейнеры

```mermaid
flowchart TB
    admin_user([Пользователь админки])
    consumer[Система-потребитель<br/>внешняя система]

    subgraph platform[Платформа feature flags]
        admin[Админка<br/>веб-приложение]
        management[API управления<br/>проверка и публикация]
        delivery[API чтения<br/>состояния, варианты и конфиги<br/>кеш активной версии]
        storage[(Хранилище конфигурации<br/>черновики, версии и история)]

        admin -->|Черновики и публикация| management
        management -->|Конфигурации и история| storage
        delivery -.->|Обновление кеша| storage
    end

    admin_user -->|Управляет флагами| admin
    consumer -->|Читает флаги и конфиги| delivery
```

## Контейнеры

- **Админка** — настройка флагов, JSON-конфигов, rollout и rollback.
- **API управления** — проверка прав и типов, публикация версий, rollback и
  запись истории изменений.
- **Хранилище конфигурации** — черновики, опубликованные версии и история
  изменений.
- **API чтения** — вычисление состояний и вариантов, а также выдача
  JSON-конфигов из кеша активной версии.

Запросы потребителей поступают только в API чтения. При обработке запроса оно не
обращается к админке, API управления или хранилищу. Хранилище используется
только при обновлении активной версии в кеше.

## Точки расширения

| Сценарий                         | Решение и причина                                                                                                                                                                                                                                                                            | Когда убрать                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Добавление ограничения по стране | В `Delivery Service` перед rollout вызывается отдельный обработчик страны. Если страна не подходит или не передана, флаг выключен. Без условия страны сохраняется прежнее поведение. Расчёт rollout и A/B-варианта по идентификатору пользователя не меняется; общий движок правил не нужен. | Если таргетинг по стране убран из продукта. |
| Фильтр истории по автору         | Отдельная точка расширения не нужна: фильтр остаётся в API и на странице истории.                                                                                                                                                                                                            | —                                           |
| Замена RabbitMQ                  | Общий интерфейс для разных брокеров заранее не нужен: изменение затронет несколько модулей, но запроса на него нет.                                                                                                                                                                          | —                                           |

## Что показало задание

- В [PublishedConfiguration](14-sync-async-contracts.md#событие-publishedconfiguration) пока нет условия страны. Нужна новая версия контракта: сначала обновляются все реплики `Delivery Service`, затем разрешается публикация нового условия. Старый обработчик не должен молча его игнорировать.
- Страна нужна не только в настройках флага: потребитель должен передавать её в контексте запроса, а `Delivery Service` — учитывать в ключе кеша ответа. Иначе при смене страны может вернуться прежний результат.
- `History Service` хранит метаданные, а не настройки флага, поэтому таргетинг его не меняет. Автор уже есть в [ConfigurationChanged](14-sync-async-contracts.md#событие-configurationchanged), и фильтр истории не требует менять отправителя события.

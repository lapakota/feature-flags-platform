# Платформа feature flags

Платформа позволяет через админку управлять флагами и типизированными JSON-конфигами, постепенно включать изменения для пользователей и проводить A/B-эксперименты. Состояния флагов и конфиги доступны через API.

## Архитектурные драйверы

- частые запросы состояний не должны перегружать платформу;
- флаги должны поддерживать rollout с шагом `1%` и rollback;
- назначение варианта должно быть стабильным для одного субъекта;
- JSON-конфиги должны проверяться по объявленному типу перед публикацией;
- изменения сначала сохраняются как черновик, применяются только после явной
публикации, а история публикаций и откатов сохраняется.

# Кеширование платформы

## Данные проекта

- index.html и файлы с хешем в имени: JavaScript, CSS, шрифты, изображения
- список флагов с краткими данными, подробности каждого флага и история изменений
- черновики, права пользователя и ответы на сохранение, публикацию и rollback
- опубликованные конфигурации
- состояния флагов, варианты экспериментов и JSON-конфиги для пользователя

## Точки кеширования

| Где           | Что хранится                                                                                                |
| ------------- | ----------------------------------------------------------------------------------------------------------- |
| Браузер       | index.html и файлы с хешем; список флагов, подробности флага и история — с проверкой актуальности у сервера |
| CDN / edge    | index.html и файлы с хешем                                                                                  |
| Сервер        | Опубликованные конфигурации и рассчитанные ответы для пользователей — только в кеше `Delivery Service`      |
| Не кешируются | Черновики, права пользователя и ответы на сохранение, публикацию и rollback                                 |

## Стратегии инвалидации

| Данные                                                         | Как обновляются                                                                            | Обоснование                                                |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| index.html                                                     | Хранится недолго, затем проверяется по ETag                                                | После релиза должна открываться новая версия админки       |
| Файлы с хешем в имени                                          | При изменении файла меняется хеш в имени                                                   | Браузер скачивает изменённый файл по новому адресу         |
| Список флагов, подробности флага и история                     | Проверка актуальности по ETag; повторный запрос после изменений                            | На экране должны быть видны последние изменения            |
| Черновики, права и ответы на сохранение, публикацию и rollback | Кеша нет, очищать нечего                                                                   | Для редактирования и проверки прав нужны свежие данные     |
| Опубликованные конфигурации                                    | После публикации или rollback сервис загружает новую версию целиком и переключается на неё | Флаги и конфиги в одном ответе должны быть из одной версии |
| Состояния, варианты и конфиги для пользователя                 | Номер версии входит в ключ кеша; старые записи удаляются по TTL                            | После смены версии старый результат больше не подходит     |

## Что уточнить у бэкенда

- Какие значения Cache-Control и сроки хранения задать для каждой группы данных.
- Как сервер рассчитывает ETag и проверяет, изменились ли данные.
- Какие заголовки запроса нужно указать в Vary.
